# Llama

### Meta's open-source large language model family

Llama is Meta's family of open-weight language models, ranging from 1B to 405B parameters. Freely available for research and commercial use, Llama models power thousands of applications and fine-tunes worldwide.

<br>

---

## Features

| | |
|:---|:---|
| **Open Weights** | Full model weights available for download — modify, fine-tune, deploy |
| **Multiple Sizes** | 1B to 405B variants cover everything from mobile to datacenter |
| **State-of-the-Art** | Competitive with GPT-4 on reasoning, coding, and instruction-following |
| **Rich Ecosystem** | Supported by Ollama, llama.cpp, vLLM, and virtually every LLM framework |
